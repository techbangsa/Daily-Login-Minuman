Minuman Daily Login: Arsitektur & Alur

Dokumen handover · backend Express di Vercel · Shopify App Proxy + Mobile API → Shopify Flow → Growave

Ringkasnya: request selalu dimulai dari client, yaitu popup theme (lewat Shopify App Proxy) atau mobile app (lewat /mobile/*), bukan dari Flow. Backend menandai "hari ini sudah diklaim" di customer metafield, lalu memicu Shopify Flow. Workflow Flow yang menambah poin di Growave. Backend tidak pernah memanggil API Growave dan tidak menyimpan saldo. Satu-satunya API eksternal yang di-hit backend adalah Shopify Admin GraphQL.

4. Logika POST /checkin & penanganan error

Urutannya sengaja dibuat "tandai dulu, baru kirim poin", supaya satu hari tidak pernah menghasilkan poin dua kali (src/routes/checkin.js).

5. Aturan siklus 7 hari

Logika murni tanpa I/O ada di src/lib/loyalty.js. Tanggal dihitung di timezone toko (SHOP_TIMEZONE, default Asia/Jakarta), jadi pergantian hari terjadi pukul 00:00 WIB.

Isi metafield custom.loyalty_data (type json) hanya { "streak": 3, "last_checkin": "2026-11-16" }. Field lama seperti balance atau history dibuang otomatis oleh normalizeState saat penulisan berikutnya.

Endpoint Admin API: POST https://<SHOPIFY_STORE_DOMAIN>/admin/api/<SHOPIFY_API_VERSION>/graphql.json dengan header X-Shopify-Access-Token: <SHOPIFY_ADMIN_API>. Client-nya ada di src/lib/shopify.js: timeout 10 detik, maksimal 4 percobaan. Query di-retry saat throttled, 5xx, atau network error. Mutation hanya di-retry saat throttled, supaya penulisan tidak pernah terjadi dua kali.

Payload flowTriggerReceive

mutation {
  flowTriggerReceive(
    handle: "daily-checkin-completed",
    payload: {
      "customer_id":  7712345678901,   # -> field customer_reference, Flow mengisi objek customer
      "Points":       15,
      "Cycle day":    3,
      "Checkin date": "2026-11-16"
    }
  ) { userErrors { field message } }
}

Key payload harus sama persis dengan field di extensions/daily-checkin-completed/shopify.extension.toml. Kalau field diubah di salah satu tempat, ubah juga di tempat lainnya, lalu jalankan shopify app deploy.

10. Hal penting / jebakan

Proses ke Growave berjalan fire-and-forget. Respons 200 hanya berarti Flow menerima trigger. Kalau step Growave gagal (paling sering karena customer tidak punya email), hari itu tetap tercatat dan poin tidak masuk. Kegagalan ini hanya terlihat di Shopify Flow → Run history, karena backend tidak mendapat callback.
Respons 202 reward_pending butuh pengecekan manual. Cek Flow Run history untuk customer dan tanggal tersebut. Kalau workflow tidak jalan, tambahkan poin manual di Growave. Log Vercel [checkin] Flow trigger result unknown dan UNDO FAILED juga perlu dipantau.
Token mobile berlaku untuk semua customer. MOBILE_API_TOKEN adalah satu token bersama, dan siapa pun yang memegangnya bisa klaim check-in atas nama customerId atau email mana saja. Token yang tertanam di app mobile bisa diekstrak. Jaga kerahasiaannya, rotasi kalau bocor, dan pertimbangkan auth per-customer (misalnya Customer Account API token) kalau risikonya tidak bisa diterima.
Flow trigger harus satu app dengan token dan App Proxy. Extension di extensions/daily-checkin-completed harus di-deploy ke app yang memiliki SHOPIFY_ADMIN_API. Custom app Flow trigger hanya jalan di Shopify Plus.
Testing memicu poin sungguhan. npm run proxy -- checkin <id> dan POST /mobile/checkin memicu Flow yang asli, sehingga poin Growave customer tersebut benar-benar bertambah.
Saldo poin tidak ada di backend. /status hanya mengembalikan posisi siklus. Saldo selalu dibaca dari Growave, baik oleh widget di theme maupun oleh mobile app.

12. Development & deploy

npm install
cp .env.example .env              # isi SHOPIFY_ADMIN_API, SHOPIFY_API_SECRET, MOBILE_API_TOKEN
npm test                          # unit test
npm run dev                       # nodemon, port 3000
npm run proxy -- status 1234567890    # GET /status lokal dengan signature App Proxy
npm run proxy -- checkin 1234567890   # PERHATIAN: memicu Flow sungguhan, poin Growave bertambah
npm run proxy:prod -- status 1234567890

# Backend: push ke repo, lalu Vercel build src/index.js (vercel.json: semua route -> src/index.js,
# includeFiles: index.html + docs/** supaya ikut ter-bundle)
# Flow trigger extension / config app:
shopify app deploy                # atau: npm run deploy

Halaman ini di-serve oleh Express di GET / (https://daily-login-minuman.vercel.app/), dan file di docs/ di-serve di /docs/*. Kalau menambah file statis lain di luar folder tersebut, tambahkan juga ke includeFiles di vercel.json.
